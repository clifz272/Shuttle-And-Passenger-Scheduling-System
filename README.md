# Shuttle and Passenger Scheduling System

A C++ application for managing shuttle services, passengers, routes, and schedules. The system supports passenger and shuttle management, schedule analysis, route planning, dispatch strategies, and file-based data persistence.

## Features

- Manage passenger and shuttle records
- Create and analyze shuttle schedules
- Plan routes between destinations
- Match passengers with available shuttle services
- Compare dispatch and priority strategies
- Persist passenger, shuttle, and location data in text files
- Visual Studio project and solution included

## Project Structure

- `*.cpp` and `*.h` — application source and header files
- `OOP_Project_Final.slnx` — Visual Studio solution
- `OOP_Project_Final.vcxproj` — Visual Studio C++ project
- `Documentation/` — project documentation, UML diagrams, and architecture diagrams
- `Location.txt` — location data
- `passengerList.txt` — passenger data
- `shuttleList.txt` — shuttle data

## Requirements

- Microsoft Visual Studio with C++ desktop development tools
- C++17-compatible compiler

## Build and Run

1. Clone the repository:

   ```bash
   git clone https://github.com/clifz272/Shuttle-And-Passenger-Scheduling-System.git
   ```

2. Open `OOP_Project_Final.slnx` in Visual Studio.
3. Select the desired configuration, such as `Debug` or `Release`.
4. Build the solution.
5. Run the project.

The application uses the included text files for its initial data. Keep these files in the working directory when running the program.
